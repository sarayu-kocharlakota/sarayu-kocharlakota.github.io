Color & Stroke Controls
Rich palette with opacity and smoothing sliders — designed to feel as tactile as real chalk or markers.

AI Highlight Color

Version 1 — Green Theme
Solvit! — Refined Identity & Echo AI
The brand evolved from Chalkmate to Solvit! with a new forest-green identity. The AI assistant was renamed Echo — communicating clarity and responsiveness.

1
Solvit! Brand & Session Header
The rebranded logo + session name ("Physics — Session 3") helps students stay organized across multiple study sessions.
2
Vector Diagram on Canvas
A student-drawn vector diagram sits on the board. The red-highlighted matrix is what Echo has been asked to analyze.
3
Red Highlight = AI Focus Zone
The dashed red box around Matrix A tells Echo exactly what to solve — no typing, just draw and highlight.
4
Echo AI Panel
Echo returns the full eigenvalue solution: det(A-λI)=0 → λ1=2, λ2=3. Clean, structured, mathematical output.
5
Draw-on-Board Action Button
"Draw u on the board!" — Echo can draw back onto the canvas, showing results as visual geometry alongside the solution.
Version 2 — Board Styles & Highlighter
Solvit! — Chalkboard, Grid & Paper Modes
The final iteration adds Board Style switching (Chalkboard / Grid / Paper) and a dedicated Highlighter tool with multiple colors, allowing users to ask multiple questions in parallel.
1
2
3
4
5
1
Board Style Switcher
Switch between Chalkboard (dark), Grid (white + lines), and Paper (plain white) to match how each student thinks and draws.
2
Multi-color Highlighter Tool
Multiple highlighter colors let users flag different regions for different questions — ask Echo to solve several things at once.
3
Progress Bar on Canvas
A subtle visual indicator at the bottom of the board tracks how much of the session's problem set has been completed.
4
Reminder Sticky Note
Echo drops a contextual sticky note on the board — "sign = char. poly, det(A-λI)=0" — bridging AI output with visual memory aids.
5
Share & Clear Board Controls
"Clear board" and "Share" in the top-right make it easy to export a session or reset for the next problem set.
